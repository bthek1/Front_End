# React Init

React init

Author

Benedict Thekkel

**Core**

- React 19 + TypeScript 6
- Vite 8 (build tool)

**Routing & Data**

- `@tanstack/react-router` — file-based routing
- `@tanstack/react-query` — server state / data fetching
- `@tanstack/react-form` — form management
- `axios` — HTTP client

**UI / Styling**

- Tailwind CSS 4 (via `@tailwindcss/vite`)
- Radix UI primitives (`label`, `select`, `separator`, `slot`)
- `lucide-react` — icons
- `class-variance-authority` + `clsx` + `tailwind-merge` — utility class management (shadcn/ui pattern)

**Testing**

- Vitest (unit/integration) + `@testing-library/react`
- Playwright (E2E)

**Dev Tooling**

- ESLint 10 + `typescript-eslint` + `eslint-plugin-react-hooks`
- Prettier
